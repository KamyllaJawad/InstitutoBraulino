# Instituto Braulino - Website Institucional

Este é o website institucional do Instituto Braulino, uma organização dedicada ao empoderamento feminino e apoio às comunidades carentes.

## Estrutura do Projeto

```
.
├── assets/
│   ├── imgs/
│   │   ├── passaro.svg
│   │   ├── passaro.png
│   │   └── [pastas de projetos]
│   └── estatuto.pdf
├── css/
│   └── style.css
├── js/
│   └── script.js
└── index.html
```

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Font Awesome

## Características

- Design responsivo

## Como Manter

### Adicionando Novos Projetos

1. Crie uma nova pasta dentro de `assets/imgs/` com o nome do projeto
2. Adicione as fotos do projeto na pasta
3. Certifique-se de que a primeira foto seja nomeada como `thumbnail.jpg`
4. O projeto será automaticamente adicionado à galeria

### Atualizando Informações

- Para atualizar informações de contato, edite o arquivo `index.html`
- Para modificar estilos, edite o arquivo `css/style.css`
- Para alterar comportamentos, edite o arquivo `js/script.js`

### Cores do Tema

As cores principais do site são:
- Rosa Principal: `#ae1a6e`
- Marrom Secundário: `#644d4b`
- Dourado Accent: `#8e7343`
- Bege Claro: `#c9b9b8`

## Como Executar Localmente

1. Clone este repositório
2. Abra o arquivo `index.html` em um navegador web moderno
3. Para desenvolvimento, recomenda-se usar um servidor local como Live Server
